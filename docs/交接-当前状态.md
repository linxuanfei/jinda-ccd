## 5. 现场对接要点（给调试员）

1. 生产态默认**不用登录**就能跑；要改检测框/规则才需要登录；
2. 画框：空白处拖 = 新建/改 ROI；Ctrl 点选多选；Ctrl 拖 = 框选；工具条「连画」可连续画多个；
3. 调机顺序：**画框 → 设抓取位置（黑白+区位）→ 调阈值（1~254，红色是被屏蔽区）→ 加规则（设计值±容差）→ 画跟踪框 → 单次检测 → 数值不符就改标定**；
4. 复检：把收集的 NG 件重新上料前，先点「复检模式」，否则复检会算进首检良率。
