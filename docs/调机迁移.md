# 调机功能迁入原 VisionApp

## 以哪份树为主干

主干是 2026-11-16 上传的原 VisionApp（压缩包解开后根目录为 `vision-main`）。老界面截图放在 `docs/old-ui/`。仓库里原先那套并行实现没有再当产品，完整快照在分支 `cursor/sop-reference-4264`。

底稿这些部分保留下来：`core`、配方、`hpro` / `hpro_import`、工位线、`security` 和原来的登录对话、`theme`、原界面（`visionapp_gui`、配方管理、机位块、产线对话框、图像视图）、`recipes/`、`config/hpro_types.json`、`config/line.json`，以及原来的 `tools/selftest_*.py`。颜色仍走 `theme` 令牌。

## 迁进来的行为

- 检测框：水平基准线只向右；选中用主题里的 NG 红；右键拖动；Ctrl 再画一框并入选择；上/下/左/右对齐、等大小、水平/垂直等间距。
- 定位：六种极性（黑色底部、白色底部、白色中下、黑色中下、白色中上、白色左侧）。阈值可用 1–254。写入 0 或 255 会警告，并且 `find_blobs` 直接拒绝这一次定位；依赖它的距离和面积也不再出数。上限 255 不会被当成「没有上限」。
- 规则：X 是间距，Y 是贴板。可写起始、终止、基准、设计值和双边容差。界面有规则预览。HPro 导入的模式 0/1/2 改为标称 ± 公差（`low - tol ~ low + tol`），不再用下限 ~ 下限+公差。模式 5 仍用第二个值。没有去解析商业二进制。
- 跟踪：跟踪框抓住黑白特征后，合成图上的平移会带动检测框。搜索范围是跟踪框再向外 80 像素，移出这个窗口就停住并说明没抓到。
- 标定：保留原来的两点标定（400 px = 20 mm 仍是 0.05 mm/px）。另加分轴标定。验收例子：143.3 px × 0.01 mm/px = 1.433，不合格；把该轴改成实物 1 mm 后读数 1.000，合格。Y 轴比例不会串进 X。
- 结果表：对象、基准、设计值、实测、面积、NG 次数、判定。画面上有 OK/NG、对象编号，以及不良品 / 良品 / 良品率 / 复检品（没有复检来源时是 0）。
- 相机：产线配置已是 6 路，数据结构不锁 4 路，界面最多加到 16。默认硬件触发。改曝光、增益或帧率会记成连续采集。迈德威视相机已经用官方 SDK 打开时，这些值会下发；还没打开就只留在配置里。安装和接口见 `docs/迈德威视相机.md`。

## 角色

生产运行不用登录。改检测框、规则、跟踪要先走原来的登录对话，成功后是管理员。改相机路数、品牌和 X/Y 比例要再走同一个登录对话，但校验的是另一份超级管理员摘要。

这份摘要默认是空的，空的时候登录失败，角色保持操作员。菜单上没有「点一下就变成管理员」。原有的工程师摘要没有改。测试只确认：登录对话被调用，以及取消登录后角色和机位数都不变。测试里不写口令。

管理员可以在登录之后另设超级管理员口令。设完也不会当场升级，还要再登录一次。

## 怎么验

无界面：

```bash
QT_QPA_PLATFORM=offscreen python tools/selftest_runner.py
QT_QPA_PLATFORM=offscreen python tools/selftest_calibration.py
QT_QPA_PLATFORM=offscreen python tools/selftest_multistation.py
QT_QPA_PLATFORM=offscreen python tools/selftest_outputs.py
QT_QPA_PLATFORM=offscreen python tools/selftest_p1.py
QT_QPA_PLATFORM=offscreen python tools/selftest_ui.py
QT_QPA_PLATFORM=offscreen python tools/selftest_ui_calib.py
QT_QPA_PLATFORM=offscreen python tools/selftest_setup.py
```

`selftest_setup.py` 覆盖双边容差、X/Y 标定、跟踪平移、对齐和等间距、阈值 0/255 拦截，以及未登录不能自行升级。

## 仍是空入口

- 迈德威视 `MV-GE500M-TPO` 走官方 MVSDK。没有这份库时打开会失败，不会用合成图冒充。其他品牌的工业相机仍然没有驱动。分辨率和曝光范围待手册确认。
- 不做真实 PLC / IO。底稿里原有的文件、串口、网络输出还在。
- 参差、共面、颜色、缺边没有补成算法。
- 不破解商业软件，也不解析加密的二进制模板。`.HPro` 仍走底稿已有的文本结构导入。
