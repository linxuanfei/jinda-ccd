# 迈德威视 MV-GE500M-TPO

铭牌：品牌迈德威视 MindVision，型号 `MV-GE500M-TPO`，序列号 `058071510393`，网口（GigE），官网 [www.mindvision.com.cn](https://www.mindvision.com.cn)。

在官网搜索这个完整型号没有规格页。分辨率、靶面、曝光范围、增益范围、帧率上下限都标成 **待手册确认**，不从型号字母或相近型号抄数字。

## 厂内要装的 SDK

到迈德威视官网的软件下载获取当前的 Windows SDK 和 Linux SDK。不要把安装包放进这个仓库。

装好之后，软件要能找到下面任一东西：

| 系统 | 官方库 |
| --- | --- |
| Windows x64 | `MVCAMSDK_X64.dll` |
| Windows x86 | `MVCAMSDK.dll` |
| Linux | `libMVSDK.so` |

也可以使用 SDK 的 Python 例程里的 `mvsdk.py`（把它所在目录放进 `PYTHONPATH`）。这是官方绑定，里面加载的就是上面的库。

环境变量 `MINDVISION_SDK` 可以指到库文件、`mvsdk.py`，或 SDK 解压后的目录。相机设置里的「SDK 路径」同样。

### Windows（机台常见）

1. 从官网下载 Windows 版 MVSDK 安装程序并安装。安装后 `MVCAMSDK_X64.dll` 一般在系统目录或 SDK 的库目录。
2. 用厂商的 GigE 配置工具把电脑网卡和相机设到同一网段。相机被别的程序占用时，`CameraInit` 会失败。
3. 启动本软件。若库不在默认搜索路径，设置 `MINDVISION_SDK` 为 `MVCAMSDK_X64.dll` 的完整路径。

### Linux

官网 SDK 压缩包里有 `install.sh`。官方说明是把对应架构的 `libMVSDK.so` 拷到系统库目录（x86_64 为 SDK 里的 `lib/x64/libMVSDK.so`），头文件拷到 `/usr/include`。网口相机还要把网卡设成固定 IP，并把反向路径过滤关掉，否则枚举数量会是 0。

```bash
export MINDVISION_SDK=/opt/MVSDK/lib/x64/libMVSDK.so
```

路径以手头那份 SDK 实际目录为准。

## 软件怎么调用

数据源类型是 `mindvision`。默认按铭牌序列号 `058071510393`、型号 `MV-GE500M-TPO` 打开。枚举不到、序列号或型号对不上，就报错并停住，不会去开另一台，也不会改用合成画面或 UVC。

下发用的是 MVSDK 这些函数：

- `CameraEnumerateDevice` / `CameraInit` / `CameraUnInit` / `CameraPlay`
- `CameraSetAeState(0)` 关掉自动曝光
- `CameraSetTriggerMode`：`0` 连续采集，`2` 硬件触发（头文件 `emSdkSnapMode`）
- `CameraSetExposureTime`：微秒。界面按毫秒填写，发送前乘 1000
- `CameraSetAnalogGain`：模拟增益档，原样下发，不套手册里没有的范围
- `CameraSetFrameRate`：整数 Hz。库里没有这个导出时，帧率下发失败并说明原因
- `CameraSetIspOutFormat`、`CameraGetImageBuffer`、`CameraImageProcess`、`CameraReleaseImageBuffer`

默认硬件触发。在相机参数里改曝光、增益或帧率后记成连续采集；相机已经用官方库打开时，这些值会下发。还没打开就只写在机位配置里，状态栏会说明尚未下发。

界面品牌可以选择「迈德威视」，型号可以选择 `MV-GE500M-TPO`。相机路数仍按产线配置，不锁死 4 路。

## 没有 SDK 或没有插相机时

打开这种数据源会抛出明确错误，内容里说明缺的是官方库或没有枚举到这只序列号。画面不会被合成图、图片目录或 UVC 替掉。合成、目录、UVC、RTSP 仍是各自的数据源，互不冒充。
