# 现场信息采集清单（第一次去现场用）

> **用途**：这一趟**不是去验收软件**，是去**钉死需求 + 拿样张 + 拍缺的截图 + 摸清相机/IO**。
> 填完这份清单回来，我们才能把跟踪框、标定、画框这些做完，第二次去现场才是"真机联调"。
> 打印或存手机，逐项打勾；拍不了的照片当场标注"下次补"。

---

## 0. 先讲清楚：当前版本能干什么、不能干什么

**别把它当调试工具交给调机师傅**——现在给会被当成"软件不行"。真实边界：

| 能力 | 现在 | 说明 |
| --- | --- | --- |
| 合成画面跑检测 | ✅ 能 | 演示用，跟实际产品无关 |
| 图片目录回放 | ✅ 能 | 把现场原图丢进一个文件夹就能跑 |
| USB 摄像头（UVC） | ✅ 能 | 插上就能出图 |
| 网络相机 RTSP | ✅ 能 | MaixCam/网络相机推流 |
| **工业相机（海康/Basler/MindVision…）** | ❌ **不能** | SDK 还没接，相机不出图 |
| **跟踪框**（补偿放料偏移） | ❌ 不能 | 产品一偏就测不准 |
| **X/Y 标定、标定值直改** | ❌ 不能 | 只有两点单一比例 |
| **直线/水平基准线、多选批量对齐** | ❌ 不能 | 只有矩形、逐个改 |
| **抓取位置（黑白×区位）、阈值 1~254、屏蔽区红色** | ❌ 不能 | 只有明暗极性 |
| 三级权限（生产免登录） | ❌ 不能 | 现在是两级、默认全权限 |
| 画矩形 ROI、改参数、判定上下限、CSV/NG 图 | ✅ 能 | 这部分可以先让他们摸界面 |

**结论**：现场如果想"看到东西"，只能给它 **UVC 摄像头** 或 **图片目录回放**；工业相机一律不出图。
