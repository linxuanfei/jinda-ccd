## 1. 总览

| 能力域 | 遗留 | VisionApp 现状 | 差距 |
| --- | --- | --- | --- |
| 帧源/相机 | 多厂商工业相机 + 参数面板 | synthetic/folder/uvc/rtsp | **大**（D-01/D-02） |

## 2. 缺失项明细

### D-01 工业相机适配 ｜ P0 ｜ 部分（MindVision 代码就绪，待 SDK+真机）

- 遗留：Basler pylon、MindVision、TIS、海康/大恒等多种驱动与 `相机类型=90` 等参数。
- 现状：无 `PylonSource` / `MvsSource` / `GalaxySource`。
- 现场确认（2026-11-16）：本线用的是 **MindVision 迈德威视**（具体型号待补）。已实现 `visionapp/sources_mindvision.py`：
  SDK 延迟加载、像素格式转换（Mono8/Bayer/RGB/BGR/YUV422）、曝光/增益/帧率/触发模式下发、按序号或序列号选相机、无 SDK 时给可操作报错；
  界面与产线配置里都能选到"工业相机 MindVision"。**剩下：放 SDK、真机出图、6 路压测、断线重连。**
  见 [`相机接入-MindVision.md`](相机接入-MindVision.md)。
- 验收：PROCESS.md L2。

### D-02 相机参数控制与持久化 ｜ P0 ｜ 缺失

- 遗留：曝光/增益/白平衡/Gamma/对比度/AOI/翻转/采集模式，按相机存 `HunterxSys.ini`。
- 现状：`meta` 仅透传，无 UI、无落盘。
- 要做：参数读写接口 + 界面"相机参数"面板 + 随机位配置保存；换机恢复。
  （MindVision 已支持通过配方/配置传 `exposure_us / gain_db / fps / trigger`；还差**界面控件**与随机位持久化。）
- **现场补充（R-03，必须）**：参数至少要含 **曝光 / 增益 / 帧率 / 触发模式**；原厂**默认硬件触发**，
  调参时必须能**切到连续模式**（否则相机不出图、参数看不到效果）。

### D-03 外部触发与信号时序 ｜ P0 ｜ 缺失

- 遗留：硬件 IO 硬触发/软触发、外部触发、输入延时/检测周期/输出延时、`OK触发`、`串口一直发信号`。
- 现状：Runner 仅 `continuous`/`single` 自由跑。
- 要做：`trigger` 模式（外部信号驱动一帧）+ 时序参数（输入/输出延时）+ 与 L3 输出联动。
- 依赖：现场触发源类型（IO 卡 / 串口 / PLC）。

### D-04 检测算子库补齐 ｜ P0 ｜ 缺失（核心复刻项）

- 遗留（`HunterxSys.ini` 名称字段 + 菜单）：PIN 间距、偏移度、正位度、参差度（含组间）、面积、检测角度、图像相似度、边缘毛边、图像比对、缺角、圆心度/真圆度、共面度等。
- 现状：`find_blobs` / `distance_pp` / `match_template` / `area_of_blob` / `angle_ppp`。
- 要做（对齐 `项目计划.md` 算子库 V1）：
  1. `caliper_edge` 卡尺找边
  2. `line_fit` / `circle_fit` 拟合
  3. `position_dev` 正位度
  4. `stagger` 参差度（+ 组间参差）
  5. `missing_corner` 缺角
  6. `similarity` 相似度/图像比对
  7. 圆心度/真圆度（若样张需要）
- 每算子：单测 + `OP_SCHEMA` 表单 + 黄金样张。

### D-05 .HPro 类型语义与判定模式确认 ｜ P0 ｜ 部分

### D-29 线形 ROI（画线工具） ｜ P0 ｜ ✅ 部分（绘制/选中/保存已完成）

- 现场原话：「点了直线之后，后面鼠标**不管往哪边偏斜，这个直线始终是往右水平延伸**」；
  「选择之后**选中的框显示红色**，**右键点击移动**」。
- **现场补充（2026-11-16）**：「**画线的功能留着**，我们产品种类不一样，**画的地方和使用都有不一样的需求**」。
- 结论：**画线功能保留为 P0**；只去掉"强制水平锁定"这一条交互（改为 `Shift` 吸附 0°/45°/90°）。
- 现状：**已实现**（`core.Rect` 支持 `shape=line` + `image_view.LineRoiItem`）：
  任意角度画线、拖端点改角度/长度、**Shift 吸附 0/45/90°**、**选中描边变红**、**右键拖动**整条线、
  随配方保存（JSON `{"shape":"line","line":[x1,y1,x2,y2]}`）、跟踪补偿时两端一起平移；
  算子按**外接矩形**裁图（现有算子可直接用）。自测 `tools/selftest_line_roi.py`。
  **剩余**：线上取点/点到线距离/卡尺算子（等现场确认线的具体用法，见 `现场实操需求.md` §5 #6）。

### D-33 跟踪框与跟踪设置 ｜ **P0（最高）** ｜ ✅ 已有（现场 R-14/R-15，原 D-23）

- 现场原话：「机台运行的时候**不会百分百把产品都放在同一个位置**，增加**跟踪框**是为了保证检测框都在正确范围」

- 现状：**已实现**（`visionapp/tracking.py` + Pipeline 前置补偿）：跟踪框学习参考图 → 每帧模板匹配得 (dx,dy) →
  所有检测框 ROI 平移后再跑算子；相似度低于 `min_score` **直接判 NG**；`apply_to` 可只补偿指定对象；
  界面有"跟踪框"按钮 + 右侧跟踪面板（偏移/相似度/最低相似度/清除）。自测 `tools/selftest_tracking.py`、`selftest_track_ui.py`；示例配方 `recipes/track_demo.json`。
