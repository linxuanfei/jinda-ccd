# 功能差距 — VisionApp vs 遗留 In-Vision（oldvision/2pin）

> 对比对象：遗留部署 `~/localcode/oldvision/2pin`（In-Vision 8.2 汉特士，无源码，
> 依据 `HunterxSys.ini`、`.HPro`、菜单字符串、`资料/` 目录整理）与本仓库当前实现。
> 优先级：**P0** 产线切换阻塞 · **P1** 对齐遗留核心能力 · **P2** 增强/专项。
> 状态列：`缺失` / `部分` / `已有`。架构取舍见 `ARCH.md`；排期与执行流程见 `PROCESS.md`。

---

## 1. 总览

| 能力域 | 遗留 | VisionApp 现状 | 差距 |
| --- | --- | --- | --- |
| 帧源/相机 | 多厂商工业相机 + 参数面板 | synthetic/folder/uvc/rtsp | **大**（D-01/D-02） |
| 检测算子 | 10+ 类型 + 二次元测量 + OCR | 5 个基础算子 | **大**（D-04） |
| 判定 | OK/NG/WT 三态 + 多模式规则 | OK/NG + range/上下限 | 中（D-06） |
| 触发/IO | 硬触发/软触发/信号延迟/IO 卡端口 | 仅连续/单次软件循环 | **大**（D-03/D-08） |
| 输出通讯 | RS232 + Modbus + 端口映射 | serial/tcp/file + 模板 | 中（D-07/D-09） |
| 配方/工程 | .HPro 工程 + 附属模板 + 点检 | JSON 配方 + .HPro 导入器 | 中（D-10/D-12） |
| 多机位 | 2 相机/多工站/相机间偏移 | 6 机位 + 合并规则 | 小（D-13） |
| 记录/统计 | CSV/图/视频/报表/良率明细 | CSV + OK/NG 图 + 良率 | 中（D-11/D-14） |

| 授权 | HASP + 机器码注册 | 无（开源） | **有意不做**（ADR-011） |

## 2. 缺失项明细

### D-01 工业相机适配 ｜ P0 ｜ 缺失

- 遗留：Basler pylon、MindVision、TIS、海康/大恒等多种驱动与 `相机类型=90` 等参数。
- 现状：无 `PylonSource` / `MvsSource` / `GalaxySource`。
- 要做：按 ADR-003 在 `sources.py` 注册三个子类（至少先做现场实际型号）；Windows 联调机验证；拔插重连。
- 验收：PROCESS.md L2。

### D-02 相机参数控制与持久化 ｜ P0 ｜ 缺失

- 遗留：曝光/增益/白平衡/Gamma/对比度/AOI/翻转/采集模式，按相机存 `HunterxSys.ini`。
- 现状：`meta` 仅透传，无 UI、无落盘。
- 要做：参数读写接口 + 界面"相机参数"面板 + 随机位配置保存；换机恢复。

### D-03 外部触发与信号时序 ｜ P0 ｜ 缺失

- 遗留：硬件 IO 硬触发/软触发、外部触发、输入延时/检测周期/输出延时、`OK触发`、`串口一直发信号`。
- 现状：Runner 仅 `continuous`/`single` 自由跑。
- 要做：`trigger` 模式（外部信号驱动一帧）+ 时序参数（输入/输出延时）+ 与 L3 输出联动。
- 依赖：现场触发源类型（IO 卡 / 串口 / PLC）。

### D-04 检测算子库补齐 ｜ P0 ｜ 缺失（核心复刻项）

- 遗留（`HunterxSys.ini` 名称字段 + 菜单）：PIN 间距、偏移度、正位度、参差度（含组间）、面积、检测角度、图像相似度、边缘毛边、图像比对、缺角、圆心度/真圆度、共面度等。
- 现状：`find_blobs` / `distance_pp` / `match_template` / `area_of_blob` / `angle_ppp`。
- 要做（对齐 `项目计划.md` 算子库 V1）：
  1. `caliper_edge` 卡尺找边
  2. `line_fit` / `circle_fit` 拟合
  3. `position_dev` 正位度
  4. `stagger` 参差度（+ 组间参差）
  5. `missing_corner` 缺角
  6. `similarity` 相似度/图像比对
  7. 圆心度/真圆度（若样张需要）
- 每算子：单测 + `OP_SCHEMA` 表单 + 黄金样张。

### D-05 .HPro 类型语义与判定模式确认 ｜ P0 ｜ 部分

- 现状：`hpro_types.json` 已映射 type 1/2/3/11/12/13/14（部分为猜测）；judge mode 仅 0/1/2/5。
- 要做：用黄金样张逐类型确认语义；补全遗留判定模式；解析站尾输出/组别行（如 `4 0 0.000 0.120 …`）；导入报告与实测对齐。

### D-06 WT 三态判定 ｜ P1 ｜ 缺失

- 遗留：OK/NG/**WT** 三态（`检测显示WT`、`WT报警`、`WTPIN`、`WT最小/最大`、`WT一直检测`）。
- 现状：仅布尔 OK/NG。
- 要做：项级/整件级 WT 区间；CSV 与界面三态显示；WT 报警通道；输出模板 `{verdict}` 取值扩展。

### D-07 输出协议完整性 ｜ P1 ｜ 部分

- 现状：模板占位符 + OK/NG 开关 + 测试发送，够联调。
- 要做：对齐现场协议文档（`资料/CCD串口通讯协议.pdf`）的帧头校验、应答重发、`串口输出距离`/`最小相关系数` 类字段（按需）。

### D-08 硬件 IO 卡输出 ｜ P1 ｜ 缺失

- 遗留：PCI1761 接线（`资料/PCI1761IO接线图.pdf`）、`OK/NG信号端口`、Port1–8 按相机 OK/NG 映射、`分段信号`×6、`振动盘信号`。
- 现状：无。
- 要做：作为 `OutputChannel` 子类（ADR-007）；端口映射进机位配置；无硬件时用文件/假通道自测。

### D-09 Modbus 通讯 ｜ P1 ｜ 缺失

- 遗留：`Modbus通信=0` 开关、`专业串口通讯`。
- 现状：无。
- 要做：若现场 PLC 走 Modbus，实现 Modbus RTU 通道（pymodbus，许可确认后引入）。

### D-10 附属模板 / 多模板 ｜ P1 ｜ 缺失

- 遗留：`附属模板路径1..5`、`IO卡触发多模板检测`。
- 现状：每机位单配方。
- 要做：机位挂多配方按条件切换（型号识别后选配方），或明确产线不需要并记入豁免。

### D-11 视频录像 ｜ P1 ｜ 缺失（ADR-011 暂缓）

- 遗留：录像区域 + 帧率 10 + `视频保存路径`。
- 现状：无。若客诉追溯需要，再立项（区域可配置、按班次分段落盘）。

### D-12 点检模式 ｜ P1 ｜ 缺失

- 遗留：点检标准数据导入/生成、点检测偏差/极差/平均值、次数/间隔/排除第一次。
- 现状：无。
- 要做：若质量要求定期点检 → 做"点检配方 + 统计报告"；否则书面豁免。

### D-13 相机间偏移 / 多工站同步 ｜ P1 ｜ 部分

- 遗留：`相机间偏移度检测`、`所有相机检测完成再发更新`、`多相机多工站`。
- 现状：6 机位独立线程 + merge_rule；缺"全部完成再统一发输出"与跨机位偏移计算。
- 要做：merge 输出同步开关；跨机位偏移项（依赖 D-04 算子）。

### D-14 记录与统计增强 ｜ P1 ｜ 部分

- 遗留：不良品细节/每个产品不良品数、总体结果窗口、`AdminTime` 进入日志、报表路径（office 导出）、OK/NG 原图或截图选择。
- 现状：CSV + NG 图 + 良率。
- 要做（按需裁剪）：
  1. 结果明细面板（每件产品各 NG 项）— 建议 P1
  2. 操作进入日志（谁在何时加载何配方）— 审计需要则 P1
  3. Excel/CSV 报表导出 — P2
  4. 原图/截图切换与 OK 图命名对齐遗留 — P2

### D-15 超级管理员与密码策略 ｜ P1 ｜ 部分

- 现状：单工程密码、SHA-256、可清除。
- 遗留：修改密码、超级管理员认证。
- 要做：改密码流程已有；若需"清除密码需二次确认 + 操作日志"补上即可。**HASP/机器码不做**（ADR-011）。

### D-16 界面布局与显示定制 ｜ P1 ｜ 缺失

- 遗留：多视图停靠与布局记忆、窗体/相机视图 OK/NG 颜色字号、检测区域边框开关、良品率显示位置、`显示每个对象不良品数`。
- 现状：固定布局 + 基本统计。
- 要做：布局/配色可配置并持久化（QSettings）；OK/NG 大字样式可调；检测区域显隐开关（部分已有 ROI）。

### D-17 中英双语 ｜ P2 ｜ 缺失

- 遗留：`Language=0`。
- 现状：中文硬编码。有海外/多语言需求再上 Qt 翻译框架。

### D-18 二次元测量仪 ｜ P2 ｜ 缺失

- 遗留：独立 `二次元影像测量仪.exe` + `Dim.ini`（线/圆捕捉、比例尺）。
- 现状：无。属独立工具模块，按产线是否需要再立项。

### D-19 OCR 字符识别 ｜ P2 ｜ 缺失

- 遗留：菜单含"字符识别"。现状无。有读码/字符需求时评估 onnxruntime 方案（ADR-001 许可约束）。

### D-20 FPC / 钥匙 / 共面度等专项 ｜ P2 ｜ 缺失

- 遗留：FPC 裁线/计数、钥匙检测区间、铁壳角共面度、圆缺口等**行业专项**。
- 现状：无。
- 要做：确认本产线是否用到；不用则永久豁免并在此注明。

### D-21 黄金样张 pytest 回归 ｜ P0 ｜ 缺失

- 现状：`tools/selftest_*.py` 行为自测，**无** `tests/`、无数值回归。
- 要做：PROCESS.md §2.4/§4 — 建 `tests/` + 样张基线 + 逐项比对报告。**切换生产前必须有。**

### D-22 打包交付物 ｜ P0 ｜ 缺失

- 现状：源码 + `run.sh`；无 PyInstaller spec、无 Windows 生产包流程实操记录。
- 要做：PROCESS.md §6 — onedir 打包 + 冒烟 + 升级回退。
